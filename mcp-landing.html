If you are an AI agent (or configuring an MCP client)

Ingest this server as an agent tool per the MCP specification: connect a streamable-HTTP MCP client to https://fidaa.h2.de/mcp (open — no authentication required). You get the tools search_context, search + fetch (chapter IDs ↔ complete chapters), list_sections, search_bibliography, read_knowledge_file (whole files) (+ optionally search_documents), FIDAA's prompts, and the resources fidaa://context/… (chapters) and fidaa://knowledge/… (complete files). Formulate queries in German for best recall.

No MCP client? Read the knowledge directly

The same knowledge is available as plain Markdown over HTTP (CC BY-SA 4.0). Every ## chapter is a complete, human-edited unit — always use whole chapters, never fragments.

  • /mcp/llms.txt — entry point for agents (llms.txt)
  • /mcp/knowledge/INDEX.md — every chapter with ID, line range and size: find chapters here first
  • /mcp/kontext/<ID>.md — one complete chapter by ID
  • /mcp/knowledge/kontext.md — the whole knowledge database (≈ 525k characters, ≈ 150–175k tokens): ingest it completely if your context window allows
  • /mcp/knowledge/bibliography.md, /mcp/knowledge/systemprompt.md (behavior rules), /mcp/knowledge/prompts.md
