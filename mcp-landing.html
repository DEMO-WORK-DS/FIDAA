FIDAA MCP endpoint

You have reached the Model Context Protocol (MCP) endpoint of FIDAA — the knowledge base of the DEMO-WORK project on Digital Streetwork. This page is shown because your client sent a plain HTTP request (e.g. a browser), which cannot complete the MCP handshake; an actual MCP request to this URL returns the protocol response instead.

If you are an AI agent (or configuring an MCP client)

Ingest this server as an agent tool per the MCP specification: connect a streamable-HTTP MCP client to https://fidaa.h2.de/mcp (open — no authentication required). You get the tools search_context, search_bibliography, list_sections (+ optionally search_documents), FIDAA's prompts, and the chapter resources fidaa://context/…. Formulate queries in German for best recall.

Project & skill
